# Architecture Promotion Records

Keep one schema-version-2 Markdown promotion record per `architectureId` in this directory. Follow `.aisteering/ARCHITECTURE_PROMOTION.md`; each record cites the approved ADRs/contracts, names one falsifiable thin scenario, and declares maturity independently from work mode and delivery state.

Run the documented `agent-steering architecture check` command to validate current maturity. Use `agent-steering architecture transition` with explicit target maturity and work mode before architecture-affecting work.
